2. 테스트 체크리스트

  • 같은 전략으로 여러 번 들어가도 순번이 자연스럽게 증가하는지
  • position polling 결과가 admitted 직전까지 안정적으로 보이는지
  • 토큰이 발급된 뒤 주문 버튼이 열리고 실제 주문이 성공하는지
  • active strategy와 다른 전략을 고르면 왜 대기열이 멈추는지 설명 가능한지
  • Redis / Kafka / Lock 전략 간 waiting time 차이를 사용자가 체감하는지
