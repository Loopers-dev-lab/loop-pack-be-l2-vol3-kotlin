# Resume Context

이전 세션의 컨텍스트를 자동으로 복원하고 작업 재개 준비를 완료하는 스킬.

## 사용법

```
/resume-context
```

## 실행 로직

### 1단계: Handoff 읽기

`.claude/handoff.md`를 읽는다.

- 파일이 없으면 "핸드오프 노트가 없습니다. 새 작업을 시작하세요." 출력 후 종료.
- 파일이 있으면 내용을 파싱하여 **미완료 작업**, **결정 사항**, **다음 세션 시작 시 할 일**을 추출한다.

### 2단계: claude-mem Observation 선별 로드

세션 시작 시 자동 로드된 startup context의 observation 인덱스(타이틀, ID, 날짜)를 확인한다.

1. handoff.md의 **날짜**와 **미완료 작업 키워드**를 기준으로 관련 observation ID를 선별한다.
2. `get_observations([선별된 ID 목록])`으로 상세 내용을 로드한다.
3. observation이 10개를 초과하면, handoff 날짜 이후 + 타이틀 관련도 상위 10개만 로드한다.

### 3단계: auto-memory 확인

현재 프로젝트의 auto-memory 인덱스(`MEMORY.md`)를 읽고, handoff 주제와 관련된 memory 파일이 있으면 함께 읽는다. memory 경로는 시스템 프롬프트에서 확인한다.

### 4단계: 요약 보고

아래 형식으로 간결하게 보고한다:

```
## 이전 세션 요약
- **완료**: [handoff에서 추출]
- **미완료**: [handoff에서 추출]
- **핵심 결정**: [observations에서 보강]

## 이번 세션 시작점
1. [다음 할 일 1]
2. [다음 할 일 2]
```

보고 후 "어디서부터 시작할까?" 로 개발자에게 주도권을 넘긴다.

## 규칙

- 대화 턴을 최소화한다. 질문-확인 왕복 없이 한 번에 읽고 요약한다.
- observation 전체를 읽지 않는다. handoff 주제와 관련된 것만 선별한다.
- 코드를 수정하지 않는다. 읽기 전용 스킬이다.
- 로드한 데이터의 토큰 양이 과도하면 (observation 10개 초과 등) 타이틀만 나열하고 "어떤 것을 상세히 볼까?" 로 개발자에게 선택권을 준다.
